Arzi

WhatsApp application-letter assistant

Arzi receives a WhatsApp message from a user, understands the issue in Indian languages, organizes the request into a formal structure, and sends back a ready-to-print PDF application letter.

  • Primary channel — WhatsApp Business Platform messaging
  • Output — Formal PDF application letter returned to the same user
  • Pricing — ₹10 per application, pay per use

CSC Pro

Desktop certificate workflow software

CSC Pro helps Maharashtra CSC operators manage customer intake, document handling, WhatsApp-linked communication, and repeated certificate application steps inside a desktop workflow connected to MahaOnline.
