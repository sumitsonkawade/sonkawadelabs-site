Arzi

WhatsApp bot for formal application letters.

Arzi listens to a user's problem in WhatsApp, understands the request in Indian languages, and sends back a ready-to-print formal application letter as a PDF.

Privacy Policy Data Deletion Terms of Service

What the product does

Core function Receives a citizen's grievance, complaint, or request through WhatsApp and transforms it into a properly formatted application letter.
Output Returns a PDF that the user can print or submit to the relevant office, authority, or institution.

How it works

  • User sends a message describing the issue or request.
  • The bot interprets the message and extracts the essential details.
  • The system prepares a formal application letter in document format.
  • The finished PDF is sent back to the same WhatsApp user.

Intended users

Audience Citizens, customers, or support users who need help drafting a formal written application in a language they can naturally use on WhatsApp.

Meta review notes

WhatsApp usage The WhatsApp Business Platform is used to receive inbound messages and return the generated PDF response to the requesting user.
Handled data User message content and the information needed to generate the requested formal application letter.
