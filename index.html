WhatsApp Bot

Arzi

A WhatsApp bot that listens to user problems in Indian languages and returns a ready-to-print formal application letter as a PDF.

Primary use Convert a citizen's message into a structured written application addressed to the relevant office or authority.
Meta review context Uses the WhatsApp Business Platform to receive messages, process the request, and send the generated PDF response back to the same user.
Pricing ₹10 per application, pay per use. No subscription and no minimum purchase. See Pricing.

Desktop Software

CSC Pro

Certificate automation software for CSC operators handling Maharashtra service applications such as caste, income, and residence certificates.

Primary use Helps operators collect customer data, run OCR, and automate repetitive MahaOnline certificate application steps from a desktop workflow.
Meta review context Includes WhatsApp onboarding and operator messaging flows tied to the product's customer communication surface.
Pricing ₹10 per application end to end, paid from prepaid wallet credits (₹1 = 1 credit, minimum top-up ₹100). See Pricing.
